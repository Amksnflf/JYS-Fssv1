域名更换记录

当前域名：api.com

换域名时，将下文 api.com 全部替换为新域名。


1. 后端

文件：backend/src/main/java/com/asterpro/modules/asset/udun/UdunProperties.java
位置：第 14 行，callbackUrl 默认值

修改前：
private String callbackUrl = "https://api.com/api/callback/udun/transaction";

修改后：
private String callbackUrl = "https://新域名/api/callback/udun/transaction";


2. 管理后台前端

文件：frontend-admin/src/pages/finance/UdunConfig.tsx
页面：财务 → 优盾接口配置 → 回调地址输入框
位置：第 64 行，placeholder

修改前：
<Input placeholder="https://api.com/api/callback/udun/transaction" />

修改后：
<Input placeholder="https://新域名/api/callback/udun/transaction" />


3. 数据库 SQL

文件：sql/aster_pro.sql
位置：t_system_config 表 udun.callback-url（id=5）

修改前：
'https://api.com/api/callback/udun/transaction'

修改后：
'https://新域名/api/callback/udun/transaction'


或者 直接登录后台 
修改  资金流水→ 优盾接口配置 → 改回调地址（新域名） → 保存



4. 用户端本地开发（可选）

frontend-app 源码无需修改，上线走相对路径 /api。

仅本地 npm run dev 且 API 连线上时，改以下文件：

文件：frontend-app/.env.local
位置：第 2 行

修改前：VITE_API_PROXY_TARGET=https://api.com
修改后：VITE_API_PROXY_TARGET=https://新域名

文件：frontend-app/.env.local.example
位置：第 3 行（示例模板，与上同步）

修改前：VITE_API_PROXY_TARGET=https://api.com
修改后：VITE_API_PROXY_TARGET=https://新域名

说明：改 .env.local 后重启 npm run dev。不影响 npm run build 上线产物。本地连本机后端时用 http://127.0.0.1:7777，无需改域名。


5. Nginx 域名配置

文件：Nginx域名配置/api.nginx.conf
文件：deploy/nginx/aster-pro.conf

将 server_name、SSL 证书路径、日志路径中的 api.com 替换为新域名。
